# Yugesh Sarikonda

I'm a high-school student interested in economics, applied mathematics,
quantitative finance and AI. I build software and study how automated systems
make decisions when the information they receive is incomplete or misleading.

My current work connects agent incentives, model evaluation and data quality.
I want someone reading a result to be able to trace it back to the experiment
that produced it.

## Selected research

| Project | Question | What you can inspect |
| --- | --- | --- |
| [Misleading claims in agent registries](https://github.com/yugeshsarikonda/agent-registry-misleading-claims) | How do performance claims influence which agents receive work? | Generated tasks, prompts, provider measurements, routing decisions and analysis code |
| [False Lean reports](https://github.com/yugeshsarikonda/mathai-false-lean-reports) | How do language models respond to misleading proof-verification feedback? | Frozen responses, scoring rules, Lean checks and offline reproduction tools |
